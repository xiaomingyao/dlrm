# 阶段 0 诊断：A2 档（global 16,384）单步分解

采集：Criteo 1TB 切片（24.5 M 行）+ MLPerf 词表；8 die；`msprof --ai-core=on --aicpu=on --model-execution=on`；20 步；解析 rank0/device_0。
窗口：首末 `lookup_backward_v2_kernel` 之间，跨度 **1.326 s / 20 步**；busy 按 20 × 42.90 ms 归一。
该轮无 profiler 步时 42.90 ms（本轮 n=3 中位为 40.27 ms，见 `fit_fixed_vs_var.md`）。

## HCCL 明细

见 `hccl_a2_16384.csv`。要点：`HcclLaunchAicpuKernel` 1.95 ms 是**纯发射开销**（6 次），不含数据传输；真正的数据搬运在 reduceScatter 3.57 + alltoall 2.17 里。

## 结论（按证据强度排序）

1. **稀疏反向是最大单项**：24 次/步 × 615 µs。26 张表各自一次 `lookup_backward_v2`，而 GPU 侧 torchrec 是按表组合批的 ⇒ 表数直接乘进步时。对应优化 WP-B：合并为统一表（26 → 1 次）。
2. **空转 29.8%**：窗口内 12.80 ms 没有任何 task，方向是减少每步 kernel 数 / 图捕获（WP-C）。
3. **通信 22.2%**：与 b8192 档（8.8%）不同，本档通信已值得单独优化；其中 1.95 ms 是纯 launch，合并 collective 有确定收益（WP-D）。
4. **稠密算力不是瓶颈**：MatMulV3 仅 1.31 ms（3.1%），bf16 收益上限 <1 ms，排最后。

## 已排除（实测，不再重复查）
